# 8-Week Education Operations Skills & Portfolio Plan

## Week 1: Excel Fundamentals and Reporting
- [ ] **Skills:** Excel basics, formulas, sorting, filtering, XLOOKUP/VLOOKUP, charts and Pivot Tables.
- [ ] **Project:** Start Project 1: Create a fictional student database with admission date, course, attendance and status.
- [ ] **Deliverable:** Excel workbook with organised data and basic summaries.

## Week 2: Student Dashboard + Professional Communication
- [ ] **Skills:** Finish Excel reporting. Practise professional emails, meeting minutes and clear business writing.
- [ ] **Project:** Complete Project 1: Build an admissions and attendance dashboard. Start Project 5: Prepare sample emails and meeting minutes.
- [ ] **Deliverable:** Student dashboard + two professional writing samples.

## Week 3: Project Coordination
- [ ] **Skills:** Timelines, task ownership, scheduling, follow-ups, risk logs and budget tracking.
- [ ] **Project:** Project 2: Prepare a school event coordination plan with tasks, deadlines, responsibilities and a sample budget.
- [ ] **Deliverable:** Complete event plan and tracker in Excel or Google Sheets.

## Week 4: Process Documentation and SOPs
- [ ] **Skills:** Process mapping, step-by-step instructions, checklists and documentation standards.
- [ ] **Project:** Project 3: Write an SOP for student admissions or student-record management. Finish the report and email samples for Project 5.
- [ ] **Deliverable:** One complete SOP + documentation pack.

## Week 5: SQL and Database Skills
- [ ] **Skills:** SELECT, WHERE, ORDER BY, GROUP BY, COUNT, SUM and basic JOIN queries.
- [ ] **Project:** Project 4: Create or use a small fictional student database and write queries for admissions, attendance and course-wise counts.
- [ ] **Deliverable:** SQL file with sample data, queries and expected results.

## Week 6: Dashboard and Reporting
- [ ] **Skills:** Connect data to reports; practise basic charts, summary tables and dashboard interpretation.
- [ ] **Project:** Complete Project 4: Turn query results into a simple Excel dashboard or Power BI report, depending on tool availability.
- [ ] **Deliverable:** SQL query collection + dashboard/report.

## Week 7: ERP/LMS and Institutional Workflows
- [ ] **Skills:** Understand student information systems, LMS, admissions, attendance, fees, examinations, permissions and reports.
- [ ] **Project:** Map the student admission process from enquiry to enrolment. Identify where an ERP/SIS would record each step.
- [ ] **Deliverable:** One institutional workflow diagram with a short explanation.

## Week 8: Portfolio and Resume Readiness
- [ ] **Skills:** Review your skills, practise explaining projects and identify gaps honestly.
- [ ] **Project:** Organise all 5 projects into folders, update your resume, add portfolio links and begin targeted applications.
- [ ] **Deliverable:** Resume + portfolio + interview-ready project explanations.
